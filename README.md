# Work Time Alert

<img src="./public/logo.png" width="200" />

- A simple web application that triggers an audible alert when it's time to start working.

## Requirements

- Golang 1.27.1 or higher  
   - [Download](https://go.dev/dl/)

## Build and Run

```bash	
go build
```

- Linux/Mac
    - Desktop
        ```bash	
        ./work-time-alert
        ```
    - Web
        ```bash	
        ./work-time-alert --web
        ```
- Windows
    - Desktop
        ```bash	
        ./work-time-alert.exe
        ```
    - Web
        ```bash	
        ./work-time-alert.exe --web
        ```
